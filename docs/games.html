칩 게임
내 페이지 게임 상점

시스템전 (NVP) — 게임당 하루 3회

하이 앤 로우

1~10 중 하나가 뽑힙니다. 1~5는 Low, 6~10은 High. 맞히면 베팅한 만큼 받고, 틀리면 베팅한 만큼 잃습니다.

룰렛

0~36 중 하나가 뽑힙니다. 색상/홀짝은 1:1, 특정 숫자 적중은 35배. 0이 나오면 색상·홀짝 베팅은 모두 패배합니다.

레드 앤 블랙

카드 색을 맞히는 단순 확률 게임입니다 (1:1).

블랙잭 (시스템전)

양쪽 모두 16 이하면 자동으로 카드를 더 받고 17 이상이면 멈추는 표준 룰로 자동 진행됩니다. 블랙잭(카드 2장으로 21) 승리 시 1.5배, 일반 승리는 1배, 무승부는 베팅 반환.

러시안 룰렛

6칸 중 1칸만 위험합니다. 도전 단계(1~5)를 미리 정하고 한 번에 결과가 나옵니다 — 단계가 높을수록 생존 확률은 낮지만 배당은 커집니다. (생존 확률 = (6-단계)/6)

대인전 (PVP) — 하루 무제한

게임 만들기

게임을 만들면 베팅한 칩이 먼저 차감되고 입장 코드가 발급됩니다. 다른 러너에게 코드를 알려주면, 코드를 입력해 참가합니다. 게임이 끝나면 코드는 만료됩니다.

코드로 참가하기

참가하는 순간 바로 승부가 결정됩니다. 블랙잭은 양쪽 패를 자동으로 진행해 비교하고, 숫자 하이 앤 로우는 각자 1~100 중 하나를 뽑아 높은 쪽이 이깁니다.

칩 환전

칩의 실제 가치는 공개되지 않지만, 환전 시 그 순간의 가치 비율로 자동 계산됩니다. 계산 결과 소수점은 버림 처리됩니다.
